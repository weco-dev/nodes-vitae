# Add Markdown Support to Demo Assessment Questions

## Problem Statement

The demo assessment system (`/demo/take`) currently does not support markdown rendering in question titles, help content, reporting information, and documentation fields. The production assessment system (`/assessment/take`) already has full markdown support with react-markdown, but this functionality is missing from the demo experience.

## Objective

Implement identical markdown support for demo assessment questions to match the production system exactly, ensuring feature parity between demo and production experiences.

## Technical Requirements

### 1. Markdown Support Scope
- **Question titles** - Support markdown formatting in question text
- **Help content** - Support markdown in contextual guidance
- **Reporting content** - Support markdown in compliance information  
- **Documentation content** - Support markdown in additional resources

### 2. Supported Markdown Features
- **Bold text** using `*text*` or `**text**` syntax
- **Italic text** using `_text_` or `*text*` syntax
- **Links** using `[text](url)` syntax
- **Lists** (bulleted and numbered)
- **Line breaks** and paragraph formatting
- All standard GitHub-flavored markdown features

### 3. Technical Implementation Strategy
- **Library**: Use `react-markdown` (already installed) - same as production
- **Approach**: Extend existing `SurveyComponent` to handle demo mode markdown rendering
- **Code Reuse**: Minimize duplication by leveraging existing markdown rendering logic
- **Security**: Implement same XSS protection as production system

## Files to Modify

### Primary Implementation
1. **`app/components/assessment/survey-component.tsx`**
   - Extend existing markdown rendering to support demo mode
   - Ensure `isDemo` prop triggers same markdown processing as production

### Supporting Files
2. **`scripts/import-demo-questions.ts`**
   - Update Excel import to handle markdown syntax preservation
   - Mirror the markdown handling logic from `scripts/import-questions.ts`
