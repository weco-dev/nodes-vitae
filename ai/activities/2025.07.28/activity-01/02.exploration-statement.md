# Question Groups Implementation - Exploration Statement

## Research Summary

Based on my research and your clarifications, here are the **SurveyJS
implementation options** for Question Groups:

## SurveyJS Implementation Options

### Option A: SurveyJS Panels (Recommended by SurveyJS)

**Pros:**

- Built-in support for question grouping
- Automatic expand/collapse functionality
- Native SurveyJS question numbering and navigation
- Proper accessibility and keyboard navigation
- Less custom code to maintain

**Cons:**

- Panels group questions on the same page (not separate pages)
- May require custom styling to match your design
- Less control over individual umbrella question navigation

### Option B: Custom Implementation

**Pros:**

- Full control over navigation and UI behavior
- Matches exactly your "one question per page" pattern
- Can implement exact Typeform-like behavior
- Perfect integration with existing navigation system

**Cons:**

- More complex implementation
- Need to handle all edge cases manually
- More code to maintain and test

**Recommendation:** Given your requirement for "one page per question" and
existing navigation architecture, **Option B (Custom Implementation)** is the
better choice.

# **PROJECT BRIEF: Question Groups Implementation**

## **Overview**

Implement Typeform-style Question Groups in the ESG Assessment platform. This
feature allows creating umbrella questions that group related sub-questions,
providing better organization and navigation for complex assessment sections.

## **Technical Requirements**

### **1. Data Structure Changes**

**File:** `app/utils/assessment-questions.ts`

Add support for umbrella questions and sub-questions:

```typescript
interface AssessmentQuestion {
	// Existing fields...
	type: 'radiogroup' | 'text' | 'group' // Add 'group' type
	parentQuestionId?: string // New field for sub-questions

	// For umbrella questions (type: 'group'):
	// - No choices or input requirements
	// - Only title, help, reporting, docs fields
	// - Acts as navigation stop only
}
```

**Example Implementation:**

```typescript
// Umbrella question
{
  questionId: 'environmental_overview',
  name: 'environmental_overview',
  type: 'group',
  title: 'Environmental Impact Assessment',
  section: 'SEZIONE 0',
  help: 'This section covers your organization\'s environmental practices...',
  reporting: 'Required for ESG compliance reporting...',
  docs: 'Reference documentation for environmental standards...'
}

// Sub-questions
{
  questionId: 'env_energy_source',
  name: 'env_energy_source',
  type: 'radiogroup',
  parentQuestionId: 'environmental_overview',  // References umbrella
  title: 'What is your primary energy source?',
  // ... rest of question config
}
```

### **2. SurveyJS Integration**

**File:** `app/components/assessment/survey-component.tsx`

**Changes Required:**

1. **Question Processing:** Filter umbrella questions to create navigation-only
   pages
2. **Page Generation:** Create separate pages for umbrella questions with no
   input elements
3. **Sub-question Display:** Show umbrella question title above sub-questions
4. **Progress Tracking:** Exclude umbrella questions from completion
   calculations

**Implementation Details:**


### **3. Progress Bar Updates**

**Files:**

- `app/components/assessment/responsive-progress-bar.tsx`
- `app/components/assessment/assessment-navigation.tsx`

**Visual Changes:**

- **Umbrella Question Dots:** Use diamond/square shape or distinct color (e.g.,
  blue) to differentiate from regular questions
- **Special Neutral State:** Always show umbrella questions as neutral (neither
  completed nor current highlighting)
- **Progress Calculation:** Exclude umbrella questions from total count and
  percentage calculations

**Implementation:**

```typescript

		// ... existing cases

```

### **4. Navigation Flow**

**File:** `app/routes/assessment+/take.tsx`

**Navigation Logic:**

1. **Umbrella Question Pages:** Show only title, help content, and navigation
   buttons (no input form)
2. **Sub-question Display:** Include umbrella question title between field name
   and question title
3. **Progress Navigation:** Clicking umbrella dots navigates to umbrella page
   (not first sub-question)
4. **Sequential Navigation:** Previous/Next buttons move through umbrella
   questions too, like regular questions

## **Acceptance Criteria**

✅ **Data Structure:** Umbrella questions defined with `type: 'group'` and
sub-questions reference via `parentQuestionId`

✅ **Navigation:** Users can navigate to umbrella questions and see them as
separate pages (as every question is now in a separate page)

✅ **Progress Bar:** Umbrella questions show with distinct visual styling and
neutral state

✅ **Progress Calculation:** Only answerable questions counted in progress
percentages

✅ **Sub-question Display:** Umbrella question title visible on sub-question
pages

✅ **SurveyJS Integration:** Umbrella questions create navigation-only pages
with no input forms

✅ **Backward Compatibility:** Feature works alongside existing 88 questions
without breaking changes

This brief provides a comprehensive roadmap for implementing Question Groups
while maintaining the existing assessment architecture and user experience.
