# Comprehensive Code Change Plan: ESG Assessment Form Enhancement

## 1. Executive Summary

This comprehensive implementation plan adds markdown support for survey question titles, displays field names for user context, and restructures the accordion system from a single `descriptions` array to three separate fields (`help`, `reporting`, `docs`). The changes maintain the existing real-time persistence, responsive design, and robust error handling while enhancing the user experience with better contextual information and structured help content.

### Key Changes Overview:
1. **Markdown Title Support**: Enable markdown formatting in SurveyJS question titles with field name display
2. **Accordion Restructuring**: Replace `descriptions: string[]` with `help?: string`, `reporting?: string`, `docs?: string`
3. **Import Script Updates**: Modify Excel processing to handle new three-column structure
4. **UI Enhancements**: Add styling for new elements maintaining mobile-first responsive design

```typescript
survey.onTextMarkdown.add((sender, options) => {
  // Only process question titles to avoid interfering with other text elements
  if (options.element && 
      (options.element.includes('sv_q_title') || 
       options.element.includes('.sv_q_title'))) {
    
    const question = sender.getQuestionByName(options.name)
    if (question) {
      // Get field name for display
      const fieldName = question.name || 'question'
      
      // Process markdown content safely
      const markdownContent = options.text || ''
      
      // Create HTML structure with field name and markdown title
      const fieldNameHtml = `<div class="question-field-name">${escapeHtml(fieldName)}</div>`
      const titleHtml = `<div class="question-title-markdown">${processMarkdownSafely(markdownContent)}</div>`
      
      options.html = fieldNameHtml + titleHtml
    }
  }
})

// Helper function for safe HTML escaping
function escapeHtml(text: string): string {
  const div = document.createElement('div')
  div.textContent = text
  return div.innerHTML
}

// Helper function for safe markdown processing
function processMarkdownSafely(markdown: string): string {
  // Use a lightweight markdown processor or ReactDOMServer for safety
  // For now, handle basic markdown manually to avoid security issues
  return markdown
    .replace(/\*\*(.*?)\*\*/g, '<strong>$1</strong>')
    .replace(/\*(.*?)\*/g, '<em>$1</em>')
    .replace(/`(.*?)`/g, '<code>$1</code>')
    .replace(/\n/g, '<br>')
}
```
