# PROJECT BRIEF: ESG Assessment Form Enhancements

## Overview
Enhance the ESG Assessment form built with SurveyJS and React to support markdown in question titles, display question field names, and restructure the help system from a single `descriptions` array to three separate accordion sections: `help`, `reporting`, and `docs`.

## Technical Context
- **Framework**: React Router v7 with React 19
- **Survey Library**: SurveyJS (survey-core & survey-react-ui v2.2.4)
- **Styling**: Tailwind CSS with shadcn/ui components
- **Markdown**: ReactMarkdown already installed and used in accordions
- **Database**: SQLite with Prisma ORM (no schema changes needed)

## Key Files to Modify
1. `app/utils/assessment-questions.ts` - Update question interface and data
2. `app/components/assessment/survey-component.tsx` - Add markdown support and update accordion logic
3. `scripts/import-questions.ts` - Update Excel import to handle new column structure

## Requirements

### 1. Question Title Markdown Support
**Implementation**: Use SurveyJS native `onTextMarkdown` event handler

**Location**: `app/components/assessment/survey-component.tsx` in the main `useEffect` where other event handlers are registered

**Approach**:
```typescript
// Add this to the survey initialization useEffect
survey.onTextMarkdown.add((sender, options) => {
  // Convert markdown to HTML using existing react-markdown or add marked library
  options.html = markdownToHtml(options.text);
});
```

**Requirements**:
- Reuse existing markdown styling from `QuestionAccordion` component
- Include HTML sanitization for security (use DOMPurify or similar)
- Ensure consistent styling with existing accordion markdown

### 2. Field Name Display
**Display**: Show the `name` property (e.g., "question_S1.1") before each question title

**Styling Requirements**:
- Smaller font size than the title
- Muted color (use `text-muted-foreground` class)
- Appear above the title with some spacing

**Implementation**: Inject the field name during question rendering using the existing `onAfterRenderQuestion` pattern, or customize title rendering in the markdown processor.

### 3. New Accordion Structure
**Change**: Replace `descriptions: string[]` with three separate fields:

```typescript
// OLD interface
interface QuestionConfig {
  // ... other fields
  descriptions: string[]
}

// NEW interface  
interface QuestionConfig {
  // ... other fields
  help?: string
  reporting?: string
  docs?: string
}
```

**Accordion Configuration**:
- **Order**: help, reporting, docs (in that order)
- **Visibility**: Hide accordion entirely if field is empty/null
- **Titles**: Use configurable strings that can be easily changed:
  ```typescript
  const ACCORDION_TITLES = {
    help: "Help",
    reporting: "Reporting", 
    docs: "Documentation"
  }
  ```
- **Markdown**: Each field supports full markdown formatting

### 4. Data Migration
**Existing Data**: Convert current `descriptions` arrays to `help` strings:
- Take the first element from existing `descriptions` arrays
- Set as the `help` field value
- Remove the `descriptions` property entirely

**Example**:
```typescript
// OLD
descriptions: [
  "Consider all irrigation systems including drip and sprinkler",
  "Include water recycling and rainwater collection practices"
]

// NEW  
help: "Consider all irrigation systems including drip and sprinkler"
```

### 5. Import Script Updates
**File**: `scripts/import-questions.ts`

**Changes Required**:
1. Update `ImportedQuestion` interface to replace `descriptions: string[]` with `help?: string, reporting?: string, docs?: string`
2. Update `mapExcelRowToStandardRow()` function to read the new columns
3. Update `generateTypeScriptFile()` to output the new field structure
4. Remove the `processDescriptions()` function as it's no longer needed

**Excel Column Mapping**:
- `help` column → `help: string`
- `reporting` column → `reporting: string`  
- `docs` column → `docs: string`
- Remove processing for `descriptions` column

### 6. Component Updates
**File**: `app/components/assessment/survey-component.tsx`

**QuestionAccordion Component Changes**:
1. Update props interface:
   ```typescript
   interface QuestionAccordionProps {
     help?: string
     reporting?: string
     docs?: string
   }
   ```

2. Create accordions only for non-empty fields
3. Use configurable titles for each section
4. Maintain existing markdown rendering and styling

**Survey Component Changes**:
1. Add markdown support via `onTextMarkdown` event
2. Update accordion injection logic to use new field structure
3. Add field name display functionality
