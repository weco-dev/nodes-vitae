# Comprehensive Diagnostic Report: ESG Assessment Form Enhancement

## 1. Summary of the Issue

The request involves four main changes to the ESG assessment system:

1. **Markdown Support for Titles**: Enable markdown formatting in SurveyJS
   question titles, similar to existing description markdown support
2. **Field Name Display**: Show the question object's `name` property before the
   title to provide question context
3. **Accordion Structure Refactoring**: Replace the current `descriptions` array
   with three separate fields (`help`, `reporting`, `docs`) that each create
   individual accordions when populated
4. **Import Script Updates**: Modify the Excel import process to handle the new
   three-column structure instead of the single descriptions column

## 4. Impact Assessment

### Direct Impact Areas

#### QuestionConfig Interface (`assessment-questions.ts:85-256`)

- **Current Structure**: `descriptions: string[]` property
- **Required Change**: Replace with `help?: string`, `reporting?: string`,
  `docs?: string`
- **Affected Elements**: All 88 question objects in the assessmentQuestions
  array
- **Data Migration**: Existing descriptions[0] should migrate to help field

#### SurveyJS Title Rendering

- **Current State**: Plain text titles via standard SurveyJS rendering
- **Impact Location**: No existing markdown processing for titles
- **Integration Point**: Requires SurveyJS `onTextMarkdown` event handler
  implementation

#### QuestionAccordion Component (`survey-component.tsx:362-480`)

- **Current Interface**: `{ descriptions: string[] }`
- **Required Change**: `{ help?: string, reporting?: string, docs?: string }`
- **Rendering Logic**: Replace single-array mapping with conditional multi-field
  rendering
- **Title Generation**: Replace `extractTitle()` logic with fixed field names

#### Accordion Injection Logic (`survey-component.tsx:622-702`)

- **Current Process**: Searches for element.descriptions in survey JSON
- **Required Changes**: Search for help/reporting/docs fields individually
- **DOM Structure**: May need unified accordion container with multiple sections

#### Import Script Processing (`import-questions.ts:77-89`)

- **Current Function**: `processDescriptions()` handles delimiter-separated text
- **Required Changes**: Replace with direct field mapping from Excel columns
- **Column Mapping**: Update `mapExcelRowToStandardRow()` to handle new column
  structure
- **Output Generation**: Modify `generateTypeScriptFile()` for new field
  structure
