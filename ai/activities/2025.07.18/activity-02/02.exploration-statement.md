# ESG Assessment UI Improvements - Development Brief

## Project Context
You are working on an ESG (Environmental, Social, Governance) assessment platform built with React Router v7, SurveyJS, and TypeScript. The assessment contains 88 questions across 7 sections with real-time persistence.

## Current Issues to Fix

### 1. **Progress Bar Layout (Desktop)**
- **Problem**: Desktop shows progress dots in 3 rows instead of a single row
- **Solution**: Make desktop progress bar horizontally scrollable like mobile
- **Implementation**: Remove the grid layout (`flex-wrap`) and use the same horizontal scroll pattern as mobile

### 2. **Section Navigation Missing**
- **Problem**: Only current section is visible, no way to jump between sections
- **Solution**: Add a shadcn dropdown/select component to replace the current section display
- **Implementation**: Replace the existing section display component entirely with a dropdown that lists all 7 sections

### 3. **Auto-scroll Behavior**
- **Problem**: When navigating with arrows or prev/next buttons, current dot may not be visible
- **Solution**: Implement auto-scrolling that centers the current dot when possible
- **Implementation**: Add scroll behavior that applies to both arrow navigation and direct dot clicks

### 4. **Assessment State Navigation**
- **Problem**: Page loads showing first question instead of last answered question
- **Solution**: Auto-navigate to last answered question on page load
- **Implementation**: Use the `currentPageIndex` saved in the assessment model to determine starting position

### 5. **Description Display**
- **Problem**: Question descriptions not showing after form fields
- **Solution**: Fix the description injection in survey-component.tsx
- **Implementation**: Debug and fix the `onAfterRenderQuestion` handler - descriptions should appear after form fields, not as accordions

### 6. **Section Navigation Feature (New)**
- **Problem**: No way to jump between sections
- **Solution**: When section is selected from dropdown, navigate to **first question of that section** (regardless of answer status)
- **Implementation**: Add navigation logic to section dropdown selection - always go to the first question of the selected section
