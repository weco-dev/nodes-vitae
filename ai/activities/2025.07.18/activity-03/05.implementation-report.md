## Technical Architecture

### Navigation State Management

The new navigation system centers around the `useAssessmentNavigation` hook, which provides:

```typescript
interface NavigationState {
  isNavigating: boolean
  currentPageIndex: number
  pendingPageIndex: number | null
  abortController: AbortController | null
}
```

**Key Features:**
- **Single Source of Truth:** All navigation state centralized in one hook
- **Async Operation Support:** AbortController pattern for canceling operations
- **Conflict Prevention:** Navigation locks during async operations
- **Timeout Protection:** 2-second timeout for navigation operations

### Component Integration Pattern

```typescript
// Parent Route (take.tsx)
const navigation = useAssessmentNavigation(
  initialPageIndex,
  totalPages,
  async (pageIndex, signal) => {
    // Update survey model
    // Save to server
    // Handle aborts and errors
  }
)

// Child Component (ResponsiveProgressBar)
<ResponsiveProgressBar
  currentIndex={navigation.currentPageIndex}
  isNavigating={navigation.isNavigating}
  onNavigatePrevious={navigation.navigatePrevious}
  onNavigateNext={navigation.navigateNext}
  canNavigatePrevious={navigation.canNavigatePrevious}
  canNavigateNext={navigation.canNavigateNext}
/>
```

### Ping Pong Effect Solution

The ping pong effect was caused by:
1. **Race Conditions:** Multiple async navigation operations starting simultaneously
2. **State Conflicts:** Progress bar and survey component updating independently
3. **Event Loops:** Programmatic navigation triggering additional events

**Solution Implementation:**
1. **Centralized State:** Single hook manages all navigation state
2. **Abort Controller:** Cancel pending operations before starting new ones
3. **Navigation Locks:** Prevent concurrent navigation operations
4. **Programmatic Detection:** Flag to distinguish user vs programmatic navigation
