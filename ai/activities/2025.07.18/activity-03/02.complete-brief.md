# Fix Assessment Navigation Ping-Pong Effect - Complete Technical Brief

## Problem Statement

The ESG assessment interface experiences a "ping-pong effect" when users rapidly
click navigation elements. This causes erratic behavior where the survey jumps
between questions unpredictably instead of smoothly navigating to the intended
question.

**Affected Navigation Elements:**

- Progress bar dots (individual question navigation)
- Progress bar arrows (left/right navigation)
- Form's previous/next buttons (SurveyJS native navigation)
- Section navigation dropdown (when implemented)

**When the Problem Occurs:**

- User clicks rapidly on right or left arrows of the progress bar
- User clicks rapidly on previous or next buttons in the form
- User clicks rapidly on different dots in the progress bar
- User rapidly switches between different navigation methods

## Root Cause Analysis

The ping-pong effect occurs because multiple navigation event handlers operate
independently without coordination:

1. **Multiple Event Sources**: Each navigation element (progress bar, form
   buttons, section dropdown) triggers its own event handler
2. **Competing State Updates**: SurveyJS model updates and React state updates
   happen asynchronously
3. **No Request Cancellation**: Previous navigation requests continue processing
   even when new ones are initiated
4. **Timeout-based Debouncing**: Current implementation uses setTimeout but
   doesn't properly cancel previous operations

## Detailed Implementation Steps

### Step 1: Create Navigation Hook

```typescript
// app/components/hooks/use-assessment-navigation.ts
export function useAssessmentNavigation(
	initialPageIndex: number,
	totalPages: number,
	onNavigate: (pageIndex: number) => Promise<void>,
) {
	const [navigationState, setNavigationState] = useState<NavigationState>({
		isNavigating: false,
		currentPageIndex: initialPageIndex,
		pendingPageIndex: null,
		abortController: null,
	})

	const navigate = useCallback(
		async (targetPageIndex: number) => {
			// Validation
			if (targetPageIndex < 0 || targetPageIndex >= totalPages) return
			if (targetPageIndex === navigationState.currentPageIndex) return
			if (navigationState.isNavigating) {
				// Cancel previous navigation
				navigationState.abortController?.abort()
			}

			// Set up new navigation
			const controller = new AbortController()
			setNavigationState({
				isNavigating: true,
				currentPageIndex: navigationState.currentPageIndex,
				pendingPageIndex: targetPageIndex,
				abortController: controller,
			})

			try {
				await onNavigate(targetPageIndex)

				// Success - update current page
				setNavigationState({
					isNavigating: false,
					currentPageIndex: targetPageIndex,
					pendingPageIndex: null,
					abortController: null,
				})
			} catch (error) {
				if (error.name === 'AbortError') {
					// Navigation was cancelled, don't update state
					return
				}

				// Handle other errors
				setNavigationState({
					isNavigating: false,
					currentPageIndex: navigationState.currentPageIndex,
					pendingPageIndex: null,
					abortController: null,
				})
				throw error
			}
		},
		[navigationState, totalPages, onNavigate],
	)

	return {
		currentPageIndex: navigationState.currentPageIndex,
		isNavigating: navigationState.isNavigating,
		navigate,
		canNavigatePrevious:
			navigationState.currentPageIndex > 0 && !navigationState.isNavigating,
		canNavigateNext:
			navigationState.currentPageIndex < totalPages - 1 &&
			!navigationState.isNavigating,
	}
}
```
