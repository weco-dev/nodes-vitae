# Import Assessment Questions from Excel to TypeScript

## Task Overview
Create a Node.js script to import assessment questions from an Excel file into a TypeScript configuration file, replacing the existing hardcoded questions.

## Files Involved
- **Source**: `ai/activities/2025.07.18/assessment-questions.xlsx`
- **Target**: `app/utils/assessment-questions.ts`

## Excel File Structure
The Excel file contains the following columns that map exactly to the TypeScript interface:
- `questionId` → `questionId: string`
- `name` → `name: string`
- `type` → `type: 'radiogroup' | 'text'`
- `title` → `title: string`
- `descriptions` → `descriptions: string[]`
- `section` → `section: string`
- `choices` → `choices: string[]`
- `isRequired` → `isRequired: boolean`
- `score` → `score: number`
- `ignore` → (used to skip questions during import)

## Data Processing Requirements

### 1. Question Filtering
- **Skip questions** where `ignore` column is "VERO" (true)
- **Only import questions** where `ignore` column is "FALSO" (false)
- Only process questions where `type` is `'radiogroup'` or `'text'`

### 2. Boolean Value Conversion
- Convert "VERO" → `true`
- Convert "FALSO" → `false`
- Apply to both `isRequired` and `ignore` columns

### 3. Choices Field Processing
- For `radiogroup` questions: If `choices` is empty, use default choices from a constant
- For `text` questions: Set `choices` to empty array `[]`
- Create a constant: `const DEFAULT_RADIOGROUP_CHOICES = ["Non adottato", "parzialmente adottato", "totalmente adottato", "non applicabile"];`

### 4. Text Formatting (Title and Descriptions)
- Use **Markdown** format to preserve formatting from Excel
- Support: bold text, lists, line breaks, emphasis
- Store as strings that can be rendered with a Markdown parser in React

### 5. Descriptions Field Processing
- Convert from single Excel cell to string array
- Split on delimiter: `"-----"`
- Maximum 3 descriptions per question (truncate if more)
- Trim whitespace from each description

### 6. Data Validation
- Check for duplicate `questionId` values - throw error if found
- Validate required fields: `questionId`, `name`, `type`, `title`, `section`, `isRequired`, `score`
- Ensure `type` is only `'radiogroup'` or `'text'`
