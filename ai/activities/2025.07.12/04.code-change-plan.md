# Code Change Plan: ESG Assessment Workflow Enhancement

## 1. Overview of Changes

This plan implements comprehensive enhancements to the ESG Assessment feature,
focusing on improving navigation flexibility, expanding content, enhancing user
experience, and adding assessment management capabilities. The changes maintain
the existing Epic Stack patterns and TypeScript type safety throughout.

Key improvements include:

- Free navigation between questions without mandatory validation
- Expanded question set from 5 to 30 questions across 6 sections
- Finalize button with validation feedback
- Automatic assessment titles with editing capability
- Assessment deletion functionality
- Enhanced assessment details page with filtering/sorting
- Improved completion flow with score display
- Removal of export functionality
- Fixed accordion descriptions display

## 2. Setup and Configuration

### 2.1. Database Migration

Since the Assessment model doesn't have a title field, we need to add it:

```bash
npx prisma migrate dev --name add_assessment_title
```

Migration file content:

```sql
-- AlterTable
ALTER TABLE "Assessment" ADD COLUMN "title" TEXT;
```

Update schema.prisma:

```prisma
model Assessment {
  id               String    @id @default(cuid())
  userId           String
  title            String?   // NEW: Optional title field
  status           String    @default("open")
  currentPageIndex Int       @default(0)
  surveyData       String    @default("{}")
  createdAt        DateTime  @default(now())
  updatedAt        DateTime  @updatedAt
  completedAt      DateTime?

  user    User              @relation(fields: [userId], references: [id], onDelete: Cascade)
  answers AssessmentAnswer[]

  @@index([userId])
  @@index([userId, status])
}
```

No new npm packages are required. The project already has all necessary

  const [sortBy, setSortBy] = useState<'section' | 'alphabetical' | 'date'>('section')

  // Filter and sort answers
  const filteredAnswers = useMemo(() => {
    let answers = assessment.answers.map(answer => ({
      ...answer,
      parsedAnswer: JSON.parse(answer.answer),
      question: assessmentQuestions.find(q => q.questionId === answer.questionId)
    }))

    // Apply section filter
    if (sectionFilter !== 'all') {
      answers = answers.filter(a => a.section === sectionFilter)
    }

    // Apply sorting
    switch (sortBy) {
      case 'alphabetical':
        answers.sort((a, b) => (a.question?.title || '').localeCompare(b.question?.title || ''))
        break
      case 'date':
        answers.sort((a, b) => new Date(b.updatedAt).getTime() - new Date(a.updatedAt).getTime())
        break

        // Group by section order
        const sectionOrder = ['Environmental Impact', 'Resource Management', 'Waste & Emissions', 'Social Responsibility', 'Employee Relations', 'Community Engagement']
        answers.sort((a, b) => {
          const aIndex = sectionOrder.indexOf(a.section)
          const bIndex = sectionOrder.indexOf(b.section)
          return aIndex - bIndex
        })
    }

    return answers
  }, [assessment.answers, sectionFilter, sortBy])
