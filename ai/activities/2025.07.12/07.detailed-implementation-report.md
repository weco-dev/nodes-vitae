## Implementation Context

### Project Background
The ESG assessment system is a comprehensive platform built on the Epic Stack architecture (Remix + React Router v7 + TypeScript + Tailwind CSS). The system enables organizations to conduct detailed environmental, social, and governance assessments through an interactive survey interface with real-time progress tracking and data persistence.
