# Fix: Hybrid Responsive Progress Bar Implementation

## Overview

This document details the implementation of a hybrid approach to fix the SurveyJS progress bar responsiveness issues. The solution replaces the problematic SurveyJS built-in progress bar with a custom responsive component while maintaining full integration with the survey navigation system.

## Problem Analysis

### Original Issues
1. **SurveyJS Progress Bar Limitations**: Third-party library with limited responsive control
2. **CSS Override Failures**: Complex CSS overrides weren't working reliably
3. **Mobile Usability**: 30 progress dots couldn't fit properly on mobile screens
4. **Touch Interaction**: Poor mobile navigation experience

### Root Cause
SurveyJS progress bar generates complex DOM structures that are difficult to override with CSS alone, especially for responsive behavior across 30 questions.

## Solution: Hybrid Approach (#4)

### Strategy
- **Disable** SurveyJS built-in progress bar
- **Create** custom responsive progress component
- **Integrate** with SurveyJS navigation system
- **Maintain** all existing functionality

## Implementation Details

### 1. Custom Responsive Progress Bar Component

**File**: `app/components/assessment/responsive-progress-bar.tsx`

```tsx
import { cn } from '#app/utils/misc.tsx'

interface ResponsiveProgressBarProps {
	questions: Array<{ questionId: string; section: string; title: string }>
	currentIndex: number
	onPageChange: (index: number) => void
	className?: string
}

export function ResponsiveProgressBar({
	questions,
	currentIndex,
	onPageChange,
	className,
}: ResponsiveProgressBarProps) {
	const getProgressDotStatus = (index: number) => {
		if (index < currentIndex) return 'completed'
		if (index === currentIndex) return 'current'
		return 'pending'
	}

	const getProgressDotStyles = (status: string) => {
		switch (status) {
			case 'completed':
				return 'bg-primary text-primary-foreground border-primary hover:bg-primary/90'
			case 'current':
				return 'bg-primary text-primary-foreground border-primary ring-2 ring-primary/20'
			case 'pending':
				return 'bg-muted text-muted-foreground border-border hover:bg-muted/80'
			default:
				return 'bg-muted text-muted-foreground border-border'
		}
	}

	return (
		<div className={cn('w-full', className)}>
			{/* Mobile: Horizontal scrollable dots */}
			<div className="block lg:hidden">
				<div className="overflow-x-auto">
					<div className="flex gap-2 min-w-max px-4 py-3">
						{questions.map((question, index) => {
							const status = getProgressDotStatus(index)
							return (
								<button
									key={question.questionId}
									onClick={() => onPageChange(index)}
									className={cn(
										'flex-shrink-0 w-8 h-8 rounded-full border-2 text-xs font-medium transition-all duration-200 focus:outline-none focus:ring-2 focus:ring-offset-2 focus:ring-primary/50',
										getProgressDotStyles(status),
									)}
									title={`${question.section}: ${question.title}`}
								>
									{index + 1}
								</button>
							)
						})}
					</div>
				</div>
				{/* Mobile scroll indicator */}
				<div className="flex justify-center mt-2">
					<div className="text-xs text-muted-foreground">
						Question {currentIndex + 1} of {questions.length}
					</div>
				</div>
			</div>

			{/* Desktop: Grid layout */}
			<div className="hidden lg:block">
				<div className="grid grid-cols-10 gap-2 mb-4">
					{questions.map((question, index) => {
						const status = getProgressDotStatus(index)
						return (
							<button
								key={question.questionId}
								onClick={() => onPageChange(index)}
								className={cn(
									'aspect-square rounded-full border-2 text-sm font-medium transition-all duration-200 focus:outline-none focus:ring-2 focus:ring-offset-2 focus:ring-primary/50 flex items-center justify-center',
									getProgressDotStyles(status),
								)}
								title={`${question.section}: ${question.title}`}
							>
								{index + 1}
							</button>
						)
					})}
				</div>
				{/* Desktop progress text */}
				<div className="flex justify-between items-center text-sm text-muted-foreground">
					<div>Question {currentIndex + 1} of {questions.length}</div>
					<div>
						{Math.round(((currentIndex + 1) / questions.length) * 100)}% Complete
					</div>
				</div>
			</div>
		</div>
	)
}
```

**Key Features**:
- ✅ **Responsive Design**: Different layouts for mobile vs desktop
- ✅ **Status Management**: Visual states for completed/current/pending
- ✅ **Touch Optimized**: Proper touch targets (32px minimum)
- ✅ **Accessibility**: Focus states, tooltips, and keyboard navigation
- ✅ **Progress Tracking**: Question counter and completion percentage

```typescript
// Custom navigation handler
const handleProgressBarNavigation = useCallback((pageIndex: number) => {
    const surveyModel = (window as any).surveyModel
    if (surveyModel) {
        surveyModel.currentPageNo = pageIndex
    }
}, [])
```

#### 2.3 Component Integration

```tsx

    currentIndex={assessment.currentPageIndex}
    onPageChange={handleProgressBarNavigation}
```
