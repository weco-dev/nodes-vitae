## 1. Overview of Changes

This comprehensive plan enhances the ESG assessment progress bar component to provide accurate completion tracking, improved visual design, and enhanced navigation capabilities. The implementation is grounded in the existing Epic Stack architecture using Remix, React Router v7, TypeScript, and Tailwind CSS.

**Core Enhancements:**
- Visual design improvements with smaller, state-aware circles
- Navigation arrows for improved user experience
- Accurate progress tracking based on answered questions (not just position)
- Dual percentage calculations (mandatory vs. total completion)
- Validation state synchronization
- Integration with existing SurveyJS and database architecture

**Architecture Compatibility:**
- Maintains existing ResponsiveProgressBar component structure
- Preserves current data flow patterns via Remix loaders/actions
- Integrates with existing QuestionConfig interface and assessment.server.ts utilities
- Uses existing UI component patterns and Tailwind CSS design system

    .filter(q => answeredQuestions.has(q.questionId)).length
