# Complete Technical Brief: Progress Bar Enhancement

## Overview
Enhance the existing progress bar component (`app/components/assessment/responsive-progress-bar.tsx`) to properly track answered vs unanswered questions, add navigation arrows, fix percentage calculations, and improve visual design.

## Technical Implementation Details

### 1. Current State Analysis
- **Component**: `app/components/assessment/responsive-progress-bar.tsx`
- **State Management**: React useState + Remix loader/actions
- **Question Data**: Located in `app/utils/assessment-questions.ts` with `isRequired: boolean` field
- **Progress Tracking**: `currentPageIndex` stored in database via Prisma
- **Answered Questions**: Track via `surveyData` object passed to SurveyJS

### 2. Required Changes

#### 2.1 Visual Design Updates
- **Circle Size**: Change from `w-8 h-8` (32px) to `w-4 h-4` (16px) for mobile, `w-6 h-6` (24px) for desktop
- **Remove Numbers**: Remove `{index + 1}` text inside circles
- **Colors** (use Tailwind defaults):
  - **Answered**: `bg-green-500 border-green-500` (filled green)
  - **Current**: `bg-blue-500 border-blue-500` (filled blue) 
  - **Unanswered**: `bg-transparent border-gray-300` (empty circle)

#### 2.2 New Props Required
```typescript
interface ResponsiveProgressBarProps {
  questions: Array<{ questionId: string; section: string; title: string; isRequired: boolean }>
  currentIndex: number
  answeredQuestions: Set<string> // questionIds that have been answered
  onPageChange: (index: number) => void
  className?: string
}
```

#### 2.3 Navigation Arrows
- **Position**: Left and right sides of progress bar
- **Visibility**: Always visible (mobile and desktop)
- **State**: 
  - Left arrow disabled when `currentIndex === 0`
  - Right arrow disabled when `currentIndex === questions.length - 1`
- **Styling**: Use Tailwind `disabled:opacity-50 disabled:cursor-not-allowed`

#### 2.4 Percentage Calculations
Replace current single percentage with two values:
```typescript
// Current: Math.round(((currentIndex + 1) / questions.length) * 100)
// New: Two separate calculations

const mandatoryAnswered = questions
  .filter(q => q.isRequired)
  .filter(q => answeredQuestions.has(q.questionId)).length

const mandatoryTotal = questions.filter(q => q.isRequired).length

const allAnswered = questions
  .filter(q => answeredQuestions.has(q.questionId)).length

const mandatoryPercentage = Math.round((mandatoryAnswered / mandatoryTotal) * 100)
const totalPercentage = Math.round((allAnswered / questions.length) * 100)
```

**Display**: 
```
"Mandatory: 75% (6/8) | Total: 60% (12/20)"
```
