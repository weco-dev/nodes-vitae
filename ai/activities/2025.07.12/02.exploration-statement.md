# ESG Assessment Workflow Enhancement - Development Brief

## Overview

Enhance the existing ESG Assessment feature to improve user experience,
navigation, and data presentation. This task involves modifying the current
assessment workflow, expanding question content, and improving the assessment
management interface.

## Current State Analysis

The existing ESG Assessment feature is fully functional with:

- SurveyJS integration with 5 sample questions
- Auto-save functionality
- Basic progress tracking
- Assessment history and details pages
- CSV export functionality

## Required Changes

### 1. Assessment Navigation & Validation Enhancement

#### Current Issue:

- All questions are mandatory, preventing free navigation
- Users can only submit at the end after answering all questions

#### Required Changes:

**Frontend (SurveyJS Configuration):**

- Modify survey configuration to allow navigation without mandatory validation
- Implement both navigation methods:
  - **Previous/Next buttons** on each question
  - **Sidebar navigation menu** to jump directly to any question/section
- Auto-save answers when user clicks "Next" button
- Keep existing auto-save on value change

**Backend:**

- Update validation logic to be permissive during navigation
- Implement final validation only when user attempts to finalize assessment

**Files to Modify:**

- `app/components/assessment/survey-component.tsx`
- `app/utils/assessment-questions.ts`
- `app/routes/assessment+/take.tsx`

### 2. Finalize/Finish Button Implementation

#### Current Issue:

- No way to finalize assessment before completing all questions
- Users redirected automatically after completion

#### Required Changes:

**UI Implementation:**

- Add "Finalize Assessment" button in the top-right area of `/assessment/take`
  page
- Position next to the page title and description
- Button should be prominent but not interfere with form flow
- Under the butto I should show the number of mandatory questions missing to
  finish the assessment

**Functionality:**

- Clicking button should:
  - Check if all mandatory questions are answered
  - If complete: redirect to review page (`/assessment/review`)
  - If incomplete: show list of completed and missing mandatory questions, with
    ability to navigate directly to them

**Files to Modify:**

- `app/routes/assessment+/take.tsx`
- `app/utils/assessment.server.ts` (add validation function)

### 3. Question Content & Structure Expansion

#### Current Issue:

- Only 5 sample questions
- Progress UI not suitable for larger assessments

#### Required Changes:

**Question Configuration:**

- Expand from 5 to **30 questions**
- Organize into **6 sections** with descriptive names:
  1. "Environmental Impact"
  2. "Resource Management"
  3. "Waste & Emissions"
  4. "Social Responsibility"
  5. "Employee Relations"
  6. "Community Engagement"
- Questions per section can vary (2-5 questions each)
- Mix question types: radio, checkbox, rating, boolean, text

**Progress UI Enhancement:**

- Update progress indicator to handle 6 sections effectively
- Consider section-based progress display
- Ensure UI remains clean and intuitive

**Files to Modify:**

- `app/utils/assessment-questions.ts`
- `app/components/assessment/section-display.tsx`
- `app/components/assessment/survey-component.tsx`
