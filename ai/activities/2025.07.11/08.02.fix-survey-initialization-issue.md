# Fix Survey Component Initialization Issue

## Problem
The `SurveyComponent` was always showing "Loading survey..." because `surveyRef.current` was being checked during the initial render, before the `useEffect` had a chance to run and initialize the survey model.

## Root Cause
React's render cycle issue:
1. Initial render: `surveyRef.current` is `null`, component shows loading message
2. `useEffect` runs after render and sets `surveyRef.current = survey`
3. No state change occurs to trigger a re-render
4. Component remains stuck showing loading message

## Solution
Added a `useState` hook to track initialization state:
- Added `isInitialized` state variable
- Set to `false` at start of `useEffect`
- Set to `true` after survey setup is complete
- Updated render condition to check both `isInitialized` and `surveyRef.current`

## Code Changes

### File: `app/components/assessment/survey-component.tsx`

1. **Added useState import**:
```typescript
import { useEffect, useRef, useState } from 'react'
```

2. **Added initialization state**:
```typescript
const [isInitialized, setIsInitialized] = useState(false)
```

3. **Reset state at start of effect**:
```typescript
useEffect(() => {
    // Reset initialization state
    setIsInitialized(false)
    // ... rest of setup
```

4. **Set initialized after setup**:
```typescript
// Mark as initialized after all setup is complete
setIsInitialized(true)
```

5. **Reset state on cleanup**:
```typescript
return () => {
    // Reset initialization state on cleanup
    setIsInitialized(false)
    // ... rest of cleanup
}
```

6. **Updated render condition**:
```typescript
if (!isInitialized || !surveyRef.current) {
    return (
        <div className="survey-container">
            <div className="p-8 text-center">
                <p className="text-muted-foreground">Loading survey...</p>
            </div>
        </div>
    )
}
```

## Result
The survey component now properly initializes and renders the survey form instead of staying stuck on the loading message.
