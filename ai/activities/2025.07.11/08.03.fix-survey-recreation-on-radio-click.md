# Fix Survey Recreation on Radio Button Click

## Issue
When clicking radio buttons in the assessment survey, the form would disappear and show only a gray rectangle. This was caused by the survey component being recreated on every radio button interaction.

## Root Cause Analysis
Through console logging, we identified the following sequence:
1. Radio button clicked → `Survey value changed: water_usage Excellent`
2. Survey callback triggered → `Calling onValueChanged callback`
3. Parent component re-rendered → `AssessmentTake component render`
4. Survey component re-rendered → `SurveyComponent render called`
5. useEffect triggered → `SurveyComponent useEffect triggered - recreating survey`
6. Survey model recreated → `Survey model created`

The issue was that:
- The `useFetcher().submit()` call in the parent component was causing state changes that triggered re-renders
- The SurveyComponent's `useEffect` had `[surveyJson]` as dependencies, but was being triggered by other prop changes
- Each time the survey was recreated, the form would disappear temporarily

## Solution Implemented

### 1. Prevent Survey Recreation on Re-renders
Changed the useEffect dependency array from `[surveyJson]` to `[]` to ensure the survey is only created once on mount:

```typescript
useEffect(() => {
    console.log('🔄 SurveyComponent useEffect triggered')
    
    // If we already have a survey and surveyJson hasn't changed, don't recreate
    if (surveyRef.current && isInitialized) {
        console.log('✅ Survey already exists and initialized, skipping recreation')
        return
    }
    
    console.log('🆕 Creating new survey model')
    // ... survey creation logic ...
}, []) // Empty dependency array - only run on mount
```

### 2. Use Refs for Callback Functions
Stored callback functions in refs to prevent useEffect triggers:

```typescript
// Store callbacks in refs to avoid triggering useEffect
const onValueChangedRef = useRef(onValueChanged)
const onPageChangedRef = useRef(onPageChanged)
const onCompleteRef = useRef(onComplete)

// Update refs when callbacks change
onValueChangedRef.current = onValueChanged
onPageChangedRef.current = onPageChanged
onCompleteRef.current = onComplete
```

### 3. Use Refs in Event Handlers
Updated survey event handlers to use the ref versions:

```typescript
survey.onValueChanged.add((sender, options) => {
    // ... logging ...
    if (question && onValueChangedRef.current) {
        // ... question meta logic ...
        onValueChangedRef.current(options.name, options.value, questionMeta)
    }
})
```

## Files Modified

### `/app/components/assessment/survey-component.tsx`
- Added callback refs to prevent useEffect triggers
- Changed useEffect dependency array to `[]` to prevent recreation
- Added early return logic to skip survey recreation when already initialized
- Updated all survey event handlers to use ref-based callbacks
- Added console logging for debugging (can be removed in production)

### `/app/routes/assessment+/take.tsx`
- Added console logging for debugging the parent component re-renders (can be removed in production)

## Result
- Radio buttons now work correctly without causing the form to disappear
- Survey maintains its state across interactions
- Form remains visible and functional throughout the assessment process
- No more survey recreation on every radio button click
