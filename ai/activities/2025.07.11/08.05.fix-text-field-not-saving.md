# Fix Text Field Not Saving Issue

## Problem
The 5th question "Describe your ESG improvement plans for next year" (text field) was not being saved, causing:
- Missing data in assessment overview
- Answer count showing "Answers: 4" instead of "Answers: 5"

## Root Cause
Text fields in SurveyJS by default only trigger `onValueChanged` when they lose focus (blur event), not while typing. If a user completes the assessment without clicking away from the text field, the value is never saved.

## Solution
Configure the survey to trigger value changes on text input while typing by setting `textUpdateMode` to `'onTyping'`.

## Code Changes

### File: `app/components/assessment/survey-component.tsx`

**Before:**
```tsx
// Create survey model
const survey = new Model(surveyJson)
console.log('📝 Survey model created:', survey)
surveyRef.current = survey
```

**After:**
```tsx
// Create survey model
const survey = new Model(surveyJson)
console.log('📝 Survey model created:', survey)

// Configure survey to trigger value changes on text input changes
survey.textUpdateMode = 'onTyping'

surveyRef.current = survey
```

## Result
- Text fields now save their values as the user types
- The 5th question is properly saved when answered
- Answer count correctly shows "Answers: 5" when all questions are completed
