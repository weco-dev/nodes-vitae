# Fix Radio Button Value Persistence Issue

## Problem
Radio button selections in the survey were not being preserved. When users selected an option (e.g., "Fair"), the selection would revert back to the first option ("Excellent") immediately.

## Root Cause
The issue was in the `SurveyComponent` where the `useEffect` on lines 197-206 was overwriting the survey data with `initialData` every time the component re-rendered. This happened when radio buttons were clicked due to the `fetcher.submit` calls triggering re-renders.

## Solution
Modified the second `useEffect` in `survey-component.tsx` to only set initial data if the survey doesn't already have user input data, preventing overwriting of user selections.

## Code Changes

### File: `app/components/assessment/survey-component.tsx`

**Before:**
```tsx
// Update survey data when initialData changes (without recreating the survey)
useEffect(() => {
	if (surveyRef.current && initialData && Object.keys(initialData).length > 0) {
		surveyRef.current.data = initialData
	}
}, [initialData])
```

**After:**
```tsx
// Update survey data when initialData changes (without recreating the survey)
// Only update if the survey doesn't already have data to prevent overwriting user input
useEffect(() => {
	if (surveyRef.current && initialData && Object.keys(initialData).length > 0) {
		// Only set initial data if the survey is empty or has no user input
		const currentData = surveyRef.current.data
		if (!currentData || Object.keys(currentData).length === 0) {
			surveyRef.current.data = initialData
		}
	}
}, [initialData])
```

## Result
Radio button selections now persist correctly and don't revert to the first option when clicked.
