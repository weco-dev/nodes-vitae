This is the first feature I am creating for this app.

Here the Business Requirements Specification (<BRS>) for a platform focused on
ESG (Environmental, Social, and Governance) assessment specifically for the wine
industry, with particular emphasis on social sustainability. I share them to let
you understand the domain of the app and not to define the feature I want to
implement.

<BRS>
BR-01. The platform must support the wine industry in assessing social sustainability.
BR-02. The platform must allow self-assessment through ESG questionnaire and provide a synthetic score.
BR-03. The platform must offer a clear, accessible and responsive user interface.
BR-04. The platform must comply with GDPR and store data on European servers.
BR-05. The platform must allow the user to reassess themselves while saving the history of evaluations.
BR-06. The platform could offer a learning section on ESG issues and specifically on social sustainability in the wine industry.
<BRS>

I want to implement the following features

I want to define the assessment strucuture. <assessment-strucuture>

- The assessment is composed by a set of questions
- At this stage we have only 5 test questions for the assessment
- Every question has: section (string); title (string); a set of max 3
  descriptions (string) organized in an Accordion shadcn component.
- Every question has a unique identifier
- Every question has a score (it will be used for future calculations)
- Every question has a mandatory flag that can be true or false (in this stage
  all are mandatory) </assessment-strucuture>

I want to let logged in users to access to the assessment features
<assessment-features>

- A user can start a new assessment
- A user can save and pause the current assessment in an open state to finish it
  later
- A user can resume a previus assessment and continue to fill it
- A user can complete a previously started assessment clicking on a button (it
  needs to be explicit)
- A user can view past assessments.
- If a user has an open assessment, she can not start a new one
- In an assessment a user can move to the next or previous questions freely
- Handle partially answered questions when navigating back/forward
- Once the assessment is completed it is locked
- Delete/cancel an open assessment
- Archive a completed assessment
- being a one-question-at-time I save the assessment at every question
- Question numbering/progress indicators
- Ability to skip questions (if allowed)
- Review/summary page before final submission
- Confirmation dialog when trying to leave an incomplete assessment
- Search/filter past assessments by date, status, or tags
- Max number of open assessment is 1 (for now, would be nice to have a variable
  to set it)

I want the user easily navigate the assessment feature <navigation>

- Update the @app/components/app-sidebar.tsx
- A user can create a new assessment with the "quick create" main button with
  something like "start assessment".
- If one assessment is paused the "quick create" main button should show the
  resume with somethign like "continue assessment".
- A user can access to the previous assessments from the sidebar menu. I can
  show a list of the last three assessments and then I move to a list of
  assements. </navigation>

I want the user have a beautiful UI/UX experience staying coherent to the
current style of the application. I want it to be similar to Typeform's UX
renowned conversational, one-question-at-a-time approach that feels more like a
friendly chat than a traditional form. <styles>

- Shows only one question at a time in full-screen view
- user answers and automatically progresses to the next question
- Creates a linear, focused conversation flow that reduces cognitive load
- Clean, minimalist interface with lots of white space
- Readable typography for questions
- Subtle animations and micro-interactions (smooth transitions, gentle fades)
- Progress indicator usually in a thin bar at the top
- Questions are prominently displayed, often center-aligned
- Answer options are visually distinct and easy to target
- Works seamlessly across devices
- Touch-friendly interface on mobile
- Welcome screen with clear call-to-action
- Review and thank you page at the end
- Optional question numbering or progress indicators </styles>
