# Fix Boolean Question Display Issue

## Problem
The transparency_reporting question with yes/no (boolean) answer was not showing any value in the assessment/{ASSESSMENT_ID} page.

## Root Cause
The display logic in `app/routes/dashboard+/assessment.$id.tsx` did not handle boolean values properly. It only handled objects and arrays, treating booleans as regular values which resulted in empty display.

## Solution
Modified the answer display logic to explicitly handle boolean values by converting them to "Yes"/"No" text.

## Code Changes

### File: `app/routes/dashboard+/assessment.$id.tsx`

**Lines 89-97** - Updated answer display logic:

```typescript
<p className="text-sm text-muted-foreground">
	{typeof answer.parsedAnswer === 'boolean'
		? answer.parsedAnswer ? 'Yes' : 'No'
		: typeof answer.parsedAnswer === 'object'
		? Array.isArray(answer.parsedAnswer)
			? answer.parsedAnswer.join(', ')
			: JSON.stringify(answer.parsedAnswer)
		: answer.parsedAnswer}
</p>
```

**Before:**
- Boolean values were not explicitly handled
- Resulted in empty/invisible display for boolean answers

**After:**
- Boolean `true` displays as "Yes"
- Boolean `false` displays as "No"
- Other data types continue to work as before

## Context
The transparency_reporting question is defined in `app/utils/assessment-questions.ts` as:
- `questionId: 'gov-001'`
- `name: 'transparency_reporting'`
- `type: 'boolean'`
- `title: 'Do you publish annual sustainability reports?'`

## Testing
The fix ensures that boolean-type questions like transparency_reporting now display their values correctly in the assessment detail view.
